不砍生活品质

房租房贷、孩子必需品、保险是生活品质的基石，不建议砍，只优化单价。可砍的也不一刀砍掉：少花一两成、让涨幅慢下来。

只砍“无意识”的部分

单笔不心疼的外卖打车、忘了取消的会员、当时可以不花的大件，是降支出最不痛的地方。

数字由代码算，AI 只负责说人话

每一项可省金额都是确定性规则算出来的，可以追溯到具体交易；AI 不编数字。

每月一次复盘

每月初（也可以选按周、按季度）提醒你：上个月花在哪、和去年同期比怎么样、上个月的目标完成了没有、这个月做哪 3 件事。目标都能用流水自动判定。提醒邮件会带上你的目标和快要续费的订阅，默认不含金额。

怎么导出账单

随手记（推荐：一次导出全部历史）
  1. 电脑打开随手记网页版，登录后进入「导入导出 → 数据导出」，选择全部时间，导出 Excel。App 里「更多 → 导入导出 → 导出数据」也可以（需要会员）。
  2. 拿到的 Excel 里按“支出 / 收入 / 转账”分了多个工作表，直接整个文件拖进来即可。
微信支付（每次最多 3 个月）
  1. 微信「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账」，选时间范围，填邮箱。
  2. 邮箱会收到一个加密 zip，解压密码在「微信支付」公众号消息里。
  3. 不用自己解压：把 zip 直接拖进来，按提示输入密码。多个月份的 zip 可以一起拖。
支付宝（每次最多 1 年）
  1. 支付宝「我的 → 账单 → 右上角 ··· → 开具交易流水证明 → 用于个人对账」，选时间范围，填邮箱。
  2. 解压密码在支付宝消息或开具记录里。zip 直接拖进来，输入密码即可。
其他记账 App / 银行流水

鲨鱼记账、钱迹、一木记账等导出的 Excel / CSV，以及银行导出的流水，只要有“日期”和“金额”两列就能导入；有“分类”“备注”“商户”列会分析得更准。

建议：随手记记全了就只导随手记；如果同时导入微信 / 支付宝，同一笔钱可能被算两次，导入时会提示重叠情况。

使用 AI 教练前，请确认

  • 只在你点「生成复盘」或提问时，把一份支出汇总经服务器转给大模型（DeepSeek）。
  • 汇总是按月、按分类的金额、可砍清单和计划；不发送逐笔流水、账户、订单号。是否附带商户名称可以在「数据 → 设置」里关闭。
  • 服务器不保存汇总，也不保存生成的复盘，只记录调用次数和成本，用于限流。复盘存在你的设备上，登录后加密同步。
  • 发送前可以点「查看将发送给 AI 的内容」核对；发过的都记在「隐私」页的数据流向账里。
