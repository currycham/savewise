SaveWise 不是又一个记账 App。把随手记、微信、支付宝的账单导进来，它会找出无感的小额高频、还在扣钱的订阅、深夜冲动的大额消费和悄悄膨胀的分类，算出每一项一年能省多少，再陪你把它变成每月一张消费卡。

导入流水→支出体检→可砍清单→每周 3 个目标→自由基金

🔒 流水在你的浏览器里解析。不登录，数据只存在这台设备；登录后，流水先在浏览器里用你的密码加密再同步，服务器只存密文、解不开。AI 教练只收到按周、按月、按分类的汇总，发送前你可以看到完整内容。

不砍生活品质

房租、阿姨、孩子必需品、保险是高品质生活的基石，不建议砍，只优化单价。

只砍“无意识”的部分

单笔不心疼的外卖打车、忘了取消的会员、焦虑时下的单，是降支出最不痛的地方。

数字由代码算，AI 只负责说人话

每一项可省金额都是确定性规则算出来的，可以追溯到具体交易；AI 不编数字。

每周一封复盘

每周一早上，把上周花在哪、上周的目标完成了没有、这周做哪 3 件事发到你的邮箱。目标都能用流水自动判定。

怎么导出账单

随手记（推荐：一次导出全部历史）
  1. 电脑打开随手记网页版，登录后进入「导入导出 → 数据导出」，选择全部时间，导出 Excel。App 里「更多 → 导入导出 → 导出数据」也可以（需要会员）。
  2. 拿到的 Excel 里按“支出 / 收入 / 转账”分了多个工作表，直接整个文件拖进来即可。
微信支付（每次最多 3 个月）
  1. 微信「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账」，选时间范围，填邮箱。
  2. 邮箱会收到一个加密 zip，解压密码在「微信支付」公众号消息里。
  3. 不用自己解压：把 zip 直接拖进来，按提示输入密码。多个月份的 zip 可以一起拖。
支付宝（每次最多 1 年）
  1. 支付宝「我的 → 账单 → 右上角 ··· → 开具交易流水证明 → 用于个人对账」，选时间范围，填邮箱。
  2. 解压密码在支付宝消息或开具记录里。zip 直接拖进来，输入密码即可。
其他记账 App / 银行流水

鲨鱼记账、钱迹、一木记账等导出的 Excel / CSV，以及银行导出的流水，只要有“日期”和“金额”两列就能导入；有“分类”“备注”“商户”列会分析得更准。

建议：随手记记全了就只导随手记；如果同时导入微信 / 支付宝，同一笔钱可能被算两次，导入时会提示重叠情况。

使用 AI 教练前，请确认

  • AI 教练会把你的支出汇总发送给服务器，再由服务器转给大模型（DeepSeek）生成复盘和回答。
  • 发送的是按月、按分类的金额、可砍清单和计划；不发送逐笔流水、账户、订单号。是否附带商户名称可以在「数据 → 设置」里关闭。
  • 服务器不保存月度复盘和提问发送的内容，只记录调用次数和成本，用于限流。生成的每周复盘会保存在你的账号里。
  • 开启「每周复盘邮件」后，每次数据变化会把最近一周的汇总（同样不含逐笔流水）存到服务器，用于周一早上自动生成复盘；关掉邮件就删除。
  • 每次发送前都可以点「查看将发送的内容」核对。
